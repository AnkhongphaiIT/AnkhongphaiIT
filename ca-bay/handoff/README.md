# Bàn giao tài nguyên

Đây là templates và manifest kế hoạch, chưa có ảnh/âm thanh/mô hình. Claude tạo requests/incoming/validated/reports trong dự án game thật theo `14_AI_ASSET_HANDOFF.md`. Mọi file nhận từ ChatGPT do người dùng chuyển thủ công; chưa có file thì giữ planned. Không có API trả phí hoặc bot website.

`source_manifest.json` phải đồng bộ ID với `data/contracts/asset_registry.json`. `files: []` là chưa có file; không điền hash/kích thước giả. `templates/voice_lines.template.csv` chỉ chứa header để tránh nhầm dòng mẫu là kịch bản chính thức.
